===============================================================================
QUICK FIX GUIDE - BillerOrganisationPayment Not Showing in Menu
===============================================================================

PROBLEM: You executed the SQL script but still don't see the menu item.

ROOT CAUSE: The menu is cached in your session. Even though the database 
was updated, your current session is still using the old menu data.

===============================================================================
SOLUTION - Follow These Steps IN ORDER:
===============================================================================

STEP 1: Run the Diagnostic Script First
----------------------------------------
1. Open SQL Server Management Studio or SQL query tool
2. Open file: BCASApplication\Database_Scripts\Diagnostic_Check_Menu.sql
3. Execute it
4. SAVE THE OUTPUT - it will tell you:
   - If the page is in MenuMaster (should be YES)
   - If role permissions exist (should be YES)
   - What role your user GMRGOAIAL has
   - What roles exist in the system

STEP 2: Run the Enhanced Script
--------------------------------
1. Open file: BCASApplication\Database_Scripts\Add_BillerOrganisationPayment_Enhanced.sql
2. Execute it
3. This will add permissions for ALL relevant roles (PAYEE, SPONSORING, ADMINISTRATOR)

STEP 3: Clear Session and Cache
--------------------------------
CRITICAL: The menu is stored in your session. You MUST clear it!

A. In your application, LOGOUT completely
   - Click "Logout" link
   - Wait for it to redirect to Home.aspx

B. Close ALL browser windows/tabs for localhost:2323

C. Clear browser cache:
   - Press Ctrl+Shift+Delete
   - Select "Cached images and files"
   - Select "Cookies and other site data"
   - Time range: "Last hour" or "All time"
   - Click "Clear data"

D. Restart your application:
   - If using IIS: Open IIS Manager → Right-click app pool → Recycle
   - If using Visual Studio: Stop debugging (Shift+F5), then Start again (F5)

STEP 4: Login Again and Check
------------------------------
1. Navigate to http://localhost:2323/ (or your port)
2. Login with your PAYEE organization credentials
3. Look for the menu - "Online Fee Payment" should now appear under Payments

===============================================================================
IF IT STILL DOESN'T SHOW:
===============================================================================

Check 1: Verify Database Entries
---------------------------------
Run this query:

	SELECT * FROM MenuMaster 
	WHERE FormName = '~/Forms/DetailsForms/BillerOrganisationPayment.aspx'

	SELECT * FROM RoleForm 
	WHERE FormName = '~/Forms/DetailsForms/BillerOrganisationPayment.aspx'

Both should return results.

Check 2: Verify Your User's Role
---------------------------------
Run this query with YOUR username:

	SELECT u.UserName, r.RoleName
	FROM aspnet_Users u
	INNER JOIN aspnet_UsersInRoles ur ON u.UserId = ur.UserId
	INNER JOIN aspnet_Roles r ON ur.RoleId = r.RoleId
	WHERE u.UserName = 'GMRGOAIAL'  -- Replace with your username

Check if you have PAYEE, SPONSORING, or ADMINISTRATOR role.

Check 3: Verify Role in RoleForm
---------------------------------
Once you know your role from Check 2, verify it exists:

	SELECT * FROM RoleForm 
	WHERE FormName = '~/Forms/DetailsForms/BillerOrganisationPayment.aspx'
	  AND RoleName = 'YOUR_ROLE_HERE'  -- Use the role from Check 2

If NO results, manually add it:

	INSERT INTO RoleForm (RoleName, FormName, Enter_By, Enter_Date)
	VALUES ('YOUR_ROLE_HERE', 
			'~/Forms/DetailsForms/BillerOrganisationPayment.aspx', 
			'admin', 
			GETDATE())

Check 4: Access the Page Directly
----------------------------------
Try accessing the page directly without the menu:

	http://localhost:2323/Forms/DetailsForms/BillerOrganisationPayment.aspx

If you can access it directly but it's not in the menu, it's a menu 
generation issue.

If you get "Access Denied" or redirect to Home.aspx, it's a permissions issue.

===============================================================================
ALTERNATIVE: Test with a Different User
===============================================================================

If the above doesn't work, try creating a test PAYEE user:

1. Navigate to User Management in your application
2. Create a new user with PAYEE role
3. Login as that new user
4. Check if the menu appears

This will tell you if it's a user-specific issue or system-wide.

===============================================================================
DEBUGGING: Check Session Data
===============================================================================

Add this temporary code to MasterPage.master.cs Page_Load to see what's 
happening:

	// Add at the top of Page_Load method
	if (!IsPostBack)
	{
		Response.Write("UserId: " + Session["UserId"] + "<br/>");

		if (Session["Forms"] != null)
		{
			DataTable dt = (DataTable)Session["Forms"];
			Response.Write("Forms in session: " + dt.Rows.Count + "<br/>");

			foreach (DataRow row in dt.Rows)
			{
				if (row[0].ToString().Contains("Biller"))
				{
					Response.Write("Found: " + row[0].ToString() + "<br/>");
				}
			}
		}
	}

This will show if BillerOrganisationPayment.aspx is in your session's 
Forms table.

===============================================================================
LAST RESORT: Manual Menu Add
===============================================================================

If nothing works, you can add a direct hyperlink in MasterPage.master:

1. Open MasterPage.master
2. Find the menu area (around line 119)
3. Add after the Menu1 control:

	<asp:HyperLink ID="lnkBillerPayment" runat="server" 
		NavigateUrl="~/Forms/DetailsForms/BillerOrganisationPayment.aspx"
		Text="Online Fee Payment" 
		ForeColor="#990000">
	</asp:HyperLink>

This bypasses the menu system entirely.
