===============================================================================
INSTRUCTIONS TO ADD BillerOrganisationPayment.aspx TO MENU
===============================================================================

PROBLEM:
The BillerOrganisationPayment.aspx page exists but PAYEE users cannot see it
in the menu after login because it's not registered in the database.

SOLUTION:
Execute the SQL script to add the page to MenuMaster and RoleForm tables.

===============================================================================
METHOD 1: Using SQL Server Management Studio (SSMS)
===============================================================================

1. Open SQL Server Management Studio (SSMS)

2. Connect to your BCAS database server:
   - Server: localhost\SQLEXPRESS (or your SQL Server instance)
   - Database: BCAS
   - Authentication: Windows Authentication or SQL Server Authentication

3. Open the SQL script:
   - File → Open → File
   - Navigate to: D:\BCAS\BCAS_Latest_Deployed_on_Server_2026_August_11\BCASApplication\Database_Scripts\
   - Select: Add_BillerOrganisationPayment_Menu.sql
   - Click Open

4. Execute the script:
   - Click "Execute" button (or press F5)
   - Review the output messages

5. Verify the results:
   - You should see SUCCESS messages
   - Check the verification section at the end

===============================================================================
METHOD 2: Using Visual Studio / Visual Studio 2026
===============================================================================

1. In Visual Studio, open Server Explorer:
   - View → Server Explorer (or press Ctrl+Alt+S)

2. Add data connection (if not already connected):
   - Right-click "Data Connections" → Add Connection
   - Server name: localhost\SQLEXPRESS
   - Database name: BCAS
   - Click OK

3. Run the SQL script:
   - Right-click on the BCAS database connection
   - Select "New Query"
   - Open the file: BCASApplication\Database_Scripts\Add_BillerOrganisationPayment_Menu.sql
   - Copy the entire content
   - Paste into the query window
   - Right-click in query window → Execute SQL

===============================================================================
METHOD 3: Using Command Line (sqlcmd)
===============================================================================

1. Open PowerShell or Command Prompt

2. Navigate to the script directory:
   cd "D:\BCAS\BCAS_Latest_Deployed_on_Server_2026_August_11\BCASApplication\Database_Scripts"

3. Run the script using sqlcmd:

   For Windows Authentication:
   sqlcmd -S localhost\SQLEXPRESS -d BCAS -i Add_BillerOrganisationPayment_Menu.sql

   For SQL Server Authentication:
   sqlcmd -S localhost\SQLEXPRESS -d BCAS -U sa -P YourPassword -i Add_BillerOrganisationPayment_Menu.sql

4. Review the output for SUCCESS messages

===============================================================================

===============================================================================

===============================================================================
TROUBLESHOOTING
===============================================================================

ISSUE: Menu item not appearing
SOLUTION:
- Clear browser cache (Ctrl+Shift+Delete)
- Delete cookies for localhost
- Restart IIS or development server
- Verify role name is EXACTLY "PAYEE" (case-sensitive)

ISSUE: "Access Denied" or redirect to Home.aspx
SOLUTION:
- Check RoleForm has entry for PAYEE role
- Run this query to verify:
  SELECT * FROM RoleForm WHERE RoleName = 'PAYEE' 
  AND FormName LIKE '%BillerOrganisation%'

ISSUE: SQL script fails with "MenuItemCode already exists"
SOLUTION:
- The script already has logic to skip if exists
- If you still get error, manually change @NextMenuCode value

ISSUE: Cannot find parent menu (Payments)
SOLUTION:
- Run this query to find correct parent menu:
  SELECT MenuItemCode, MenuDescription FROM MenuMaster 
  WHERE MenuLevel = 1 AND WhetherLeafMenu = 'N'
- Update @PaymentsMenuCode in script with correct value
